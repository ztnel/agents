    Sources

    Keys

    j k · 5j · gg G · 42G
    Move to the character above or below on screen, keeping the column; a diagram is one stop (h/l cycle its labelled parts). Counts repeat. NG jumps to source line N.
    Ctrl-d Ctrl-u · Ctrl-f Ctrl-b · zz
    Half page / full page down and up; centre the cursor.
    [[ ]]
    Previous / next heading.
    h l · w b e · 0 ^ $
    Move by character (continuing across a paragraph's sentences), word and to the line start, first character or end. Works inside inline math; display math is one stop, like an image; on a diagram h/l cycle its labelled parts.
    { } · [[ ]] · gO
    Previous or next section heading (counts repeat) · toggle the contents sidebar (also :toc); click an entry to jump.
    gd · 2gd
    Jump to cited source; second attached citation.
    K (Shift+k)
    Inspect attached sources without leaving the text; Esc closes.
    Ctrl-o · Ctrl-i
    Back or forward through source jumps (counts repeat).
    v · V · o
    Enter VISUAL (characters) or VISUAL LINE (whole screen rows; diagrams, display math and widgets whole) and extend with motions; o swaps the selection end.
    viw · vip
    Select the inner word without adjacent spaces · select the whole paragraph.
    c · C
    Comment on the cursor line, selection or diagram element · on the whole document.
    r · Enter
    Reply to the conversation on the cursor line · show it in the panel.
    m M
    Next / previous conversation.
    Tab
    Open the floating conversation panel, then switch focus between it and the document; Esc closes the panel and returns to the document. In the panel: j/k move, r reply, Enter jump to its text. (Ctrl-w is not bound: browsers close the tab.)
    / · n N · :noh
    Search (smartcase) any text, diagram labels and inline math included, landing on the exact character; next/previous match; clear highlights.
    Enter · Shift+Enter · Esc
    Comment INSERT: send; newline; enter Normal mode in the text box.
    i a A · x · p · u
    Comment NORMAL: insert before cursor, after cursor, at line end · delete character or selection · paste clipboard once after cursor (replacing a selection) · undo. Each Insert-mode session is one undo step.
    h j k l · w b e · 0 ^ $ · gg G
    Comment NORMAL: navigate characters and logical lines · words · line edges · top/bottom. Counts repeat motions.
    v V · viw vip · y · yy · yiw yip
    Comment NORMAL: select characters/lines · word/paragraph · yank selection · yank line · yank word/paragraph to the clipboard. Esc clears a selection or closes the conversation, keeping the draft; Tab returns to the page.
    :w · :q · :wq · :e · :N
    Save as PDF via the print dialog · end the session and close the tab if the browser allows · both · reload the page · go to source line N.
    Click · Shift+click
    Move the cursor and open the conversation on highlighted text · extend a character selection.
    Enter · Esc
    On an interactive widget: use its controls; return to the document. Comments include the widget's current values.
    Esc · ?
    Clear count, selection or element · this help.
